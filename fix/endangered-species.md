## Root causes
1. **Invalid CSS custom-property colors are fed to MapLibre and Canvas (primary cause of missing/black visuals).** `lib/map-utils.ts:21-28` defines `GROUP_COLORS` with values such as `var(--warning)`, `var(--success)`, `var(--purple)`, and `var(--info)`. Those are valid for HTML/CSS popup styles, but not valid MapLibre style-spec colors or Canvas 2D colors.
   - Active marker path: `composables/useMapMarker.ts:684-715`, `toSpeciesGeoJSON()`, writes `GROUP_COLORS[...]` into GeoJSON `properties.color`; `addPointLayers()` at `:386-408` uses `['get','color']` for `circle-color` and `circle-stroke-color`. Invalid values can make the colored layers fail/vanish; the remaining intentional dark core (`rgba(5,12,20,.96)` at `:393-397`) can appear as black/unmarked dots.
   - Particle path: `lib/map-effects.ts:117-170`, `buildSpeciesConnectionFeatures()`, assigns the same CSS-var color; `createMapParticleSystem()` at `:570-592` assigns it to `ctx.strokeStyle`, `ctx.fillStyle`, and `ctx.shadowColor`. Invalid Canvas colors fall back/retain the default black appearance, directly explaining black particles. Connection line layers at `:299-331` have the same invalid-color problem.
   - Exact change points: introduce a renderer-safe hex palette (or resolve CSS vars before rendering) and use it in `toSpeciesGeoJSON()`, `buildSpeciesConnectionFeatures()`, and connection/particle rendering. Keep CSS vars only for DOM popup styling. Align the legacy `composables/useGeoJSONMarkers.ts:60-85` converter as well.

2. **Species data URL joining is fragile under a non-root deployment (conditional root cause for no markers).** `composables/useSpeciesData.ts:103-130` and `:166-202` concatenate `${baseURL}data/...`; if `NUXT_APP_BASE_URL` lacks a trailing slash, requests become `/prefixdata/...` and both indexes 404. The repository currently contains valid assets: `public/data/species/iucn-index.json` (200 records) and `icmbio-brazil-index.json` (4,615 records), all with valid numeric coordinates. Normalize/join `baseURL` in `fetchDataset()`, `fetchSpeciesIndex()`, `fetchRegionLookup()`, and `fetchRegionChunk()`; validate both root and deployed-prefix URLs.

Review these overlays only after color correction if the map remains too dark.
